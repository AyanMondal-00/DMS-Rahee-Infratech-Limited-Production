2. KENO NOTUN USER BANANOR POR PERMISSION THAKCHE NA? (ROOT CAUSE)
--------------------------------------------------------------------------------

Apni je problem ta notice korechen je notun user bananor por tar upload ba onnano
permission thakche na, tar ashol karon holo backend-e kichu HARDCODED checks ache:

A. FILE UPLOAD BLOCK ISSUE:
   - Frontend theke Super Admin notun user-ke "Admin" ba "Execution Control" (Upload capability)
     die create korleo, backend-er "backend/src/controllers/document.controller.js" (Line 44-60)-e
     shudhu purono 3 joner email hardcode kora ache:
       1) rahul.d@rahee.com
       2) om.jha@ircon.org
       3) s.mondal@rahee.com
   - Tai notun user jokhon upload korte jay, backend take error dei:
     "Forbidden: Document upload is strictly restricted to Rahul Dey, Om Jha, and Somnath Mondal."

B. FOLDER CREATE RESTRICTION:
   - "backend/src/controllers/folder.controller.js" file-eo same vabe shudhu Rahul Dey,
     Om Jha ebong Super Admin chara onno kauke folder create korte diche na.

C. EMAIL NOTIFICATION:
   - Notun user jodi 4 jon excluded list-e na thake (manish, ayush, manoj, arunabha),
     tobe se 100% email notification pabe jokhon-i kono notun document upload hobe.

3. SHORT SUMMARY
--------------------------------------------------------------------------------

- Admin & Execution Control:
  View, Download, Email pabe, kintu Upload block hoye jachhe backend-er hardcoded email check-er karone.

- Manager, Reviewer, Viewer:
